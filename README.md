# 我们的 Kimi 知识库

一体四面的统一知识库：

| 模块 | 形态 | 作用 |
| --- | --- | --- |
| 知识浏览 | 网页应用 | 日常操作台：浏览、搜索、新增、编辑 |
| 文档库 | Markdown 文件 | 知识的"源文件"，任何工具可读 |
| GitHub 仓库 | 云端副本 | 版本化、跨设备同步 |
| 技能包 | Kimi .skill | 让 Kimi 按库中知识回答 |
