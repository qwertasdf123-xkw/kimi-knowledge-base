> 会议纪要的三段式写法：结论先行、行动项明确、上下文精简。

# 高效会议纪要规范

会议纪要的核心不是"记录"，而是**推动行动**。

## 三段式结构

### 1. 结论（30 秒能读完）
- 本次会议达成了什么决定？
- 一句话写清楚，放在最前面。

### 2. 行动项（可追踪）
| 事项 | 负责人 | 截止时间 |
| --- | --- | --- |
| | | |

> 原则：每条行动项必须有唯一负责人和明确时间，否则等于没有。

### 3. 讨论要点（供缺席者了解上下文）
- 只记**分歧点和理由**，不记流水账。

## 常见反模式
- ❌ 全文照录发言 → 没人看
- ❌ "大家一致认为" → 不写清谁负责
- ❌ 会后三天才发 → 行动项已凉

## 时效要求
会议纪要应在会后 **2 小时内**发出。
