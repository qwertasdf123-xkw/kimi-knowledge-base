3.2.3 SQL 语句分类
 
DDL：定义结构（建库、建表、删表）
DML：操作表中数据（增、删、改）
DQL：查询表中数据（SELECT）
DCL：权限控制（授权、收权）
TCL：事务控制（提交、回滚）
