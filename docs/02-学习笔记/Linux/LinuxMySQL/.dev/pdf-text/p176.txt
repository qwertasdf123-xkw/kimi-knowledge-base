7.MHA高可用
 
MHA（Master High Availability）是专为 MySQL 主从复制设计的开源高可用工具，核心解决主库单点
故障问题，实现自动故障转移（0–30 秒），兼顾数据一致性，是中小规模 MySQL 集群的主流高可用方
案。
核心概念
是什么：由日本开发者 Yoshinori Matsunobu 开发，基于 Perl 实现，不改变原生主从复制逻辑，
仅解决 “故障自动切换” 痛点。
