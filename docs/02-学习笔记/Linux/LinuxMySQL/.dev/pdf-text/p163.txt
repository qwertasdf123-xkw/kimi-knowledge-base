故障：使用此方法，对时完成后，无法重启mysqld服务
原因：之前在windows端使用navicat连接过mysql
解决：pkill -9 mysql;systemctl restart mysqld

mysql主服务器配置

log-bin = master-bin                         #主服务器日志文件
log-slave-updates = true                     #从服务器更新二进制日志
