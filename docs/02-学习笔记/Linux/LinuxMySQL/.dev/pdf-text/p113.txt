二、MySQL外键关联详解（王者荣耀实战版）
 
外键（FOREIGN KEY）是多表关联的核心，也是保证数据完整性的关键，结合我们上面的王者荣耀4张
表。
1. 外键核心概念
 
外键是一张表中的字段，用来关联另一张表的主键，相当于两张表之间的“桥梁”，目的是让两张表的数据
产生关联，避免出现“无主数据”（比如没有对应英雄的皮肤、没有对应玩家的战绩）。
核心对应关系（结合我们的表）：
皮肤表（pifu）的 yingxiong_id → 关联 → 英雄表（yingxiong）的 yingxiong_id（主键）：皮肤必
须属于某一个已存在的英雄
战绩表（zhanji）的 wanjia_id → 关联 → 玩家表（wanjia）的 wanjia_id（主键）：战绩必须属于
某一个已存在的玩家
战绩表（zhanji）的 yingxiong_id → 关联 → 英雄表（yingxiong）的 yingxiong_id（主键）：战绩
必须对应某一个已存在的英雄
简单说：外键就是“约束”，约束当前表的字段值，必须在另一张表的主键中存在，不能乱填、不能
填不存在的值。
 
2. 外键的创建语法
 
外键创建分两种：建表时创建（最常用）、建表后添加，我们结合皮肤表、战绩表的案例，逐个讲解。
('菜鸡互啄', '青铜', 2),
