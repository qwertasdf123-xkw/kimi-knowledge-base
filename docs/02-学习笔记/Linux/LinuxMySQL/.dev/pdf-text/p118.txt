3. 左连接（LEFT JOIN）：保留左表全部数据
 
概念
 
左表的所有行全部保留，右表只返回匹配上的数据，匹配不上的显示 NULL。
案例：查询所有玩家，哪怕没打过战绩也要显示
 
查询结果
 
新玩家出现在结果里了！他没有战绩，所以右表的字段全部是 NULL，完美保留了左表的所有数
据。
 
SELECT 
  wj.wanjia_nicheng AS 玩家昵称,
  yx.yingxiong_ming AS 使用英雄,
  zj.shenglv AS 胜率,
  zj.zongchangci AS 总场次
FROM wanjia wj
-- 左连接：玩家表是左表，所有玩家都要保留
LEFT JOIN zhanji zj ON wj.wanjia_id = zj.wanjia_id
LEFT JOIN yingxiong yx ON zj.yingxiong_id = yx.yingxiong_id;
