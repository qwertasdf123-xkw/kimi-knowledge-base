6. 自连接 SELF JOIN

语法
同一张表：yuangong e 、yuangong l
必须起不同别名（e 员工，l 领导）
本质还是 JOIN，只是表是同一张

7. 联合查询 UNION / UNION ALL
不是左右连接，是上下拼接结果
要求：列数相同、类型对应
UNION：去重
UNION ALL：不去重，速度更快
SELECT * FROM bumen LEFT JOIN yuangong ON bumen.bumen_id = yuangong.bumen_id
UNION
SELECT * FROM bumen RIGHT JOIN yuangong ON bumen.bumen_id = yuangong.bumen_id;
