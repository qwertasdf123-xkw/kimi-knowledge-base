### 系统核心目录

- `/bin`：系统二进制文件（常用基础命令），普通用户与 root 都可用
- `/sbin`：系统管理相关命令（多用于系统维护/管理）
- `/lib`：系统调用/程序运行所需的基础函数库
- `/boot`：启动相关文件（内核、引导加载器等）
- `/dev`：设备文件（磁盘、键盘、鼠标等以文件形式呈现）
- `/etc`：系统与服务的配置文件（默认安装的服务配置通常在这里）
- `/sys`：虚拟文件系统（多为内核信息/接口，主要在内存中呈现）
- `/var`：可变数据（日志、缓存、队列等会变化增长的内容常在这里）

### 用户与软件相关目录

- `/home`：普通用户主目录
- `/root`：root 用户主目录
- `/usr`：用户级程序与库的主要集合（大量系统软件、文档与工具）
- `/opt`：第三方/可选软件安装目录（常见于手动安装的软件）
- `/srv`：服务数据目录（某些服务运行后需要保存的数据）
- `/mnt`：临时挂载点（挂载额外设备/分区时常用）
- `/tmp`：临时文件目录
### 目录类型说明

- `.`：当前目录
    
- `..`：上级目录
    
- `目录名`：指定目录
    

### 隐藏文件与隐藏目录

在 Linux 中，无论是文件还是目录，只要在命名时以 `.` 开头，即可将其设置为隐藏格式。

**示例**：`.bashrc`、`.ssh` 等都是隐藏文件或目录。
