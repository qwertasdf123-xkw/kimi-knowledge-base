# 卡片盒笔记法（Zettelkasten）入门

来自社会学家卢曼的方法——他靠这套系统写了 70 本书。

## 三条核心规则

### 1. 原子化
一条笔记只装**一个**想法。太长就拆开。

### 2. 用自己的话写
复制粘贴 ≠ 学习。转述的过程才是理解的过程。

### 3. 用链接代替分类
- 不要把时间花在"这条该放哪个文件夹"
- 问的是："这条和哪些已有笔记有关？"
- 知识的价值在网络密度，不在目录整齐

## 在本知识库中的实践
- 每条知识条目 = 一张卡片
- 用标签建立横向连接
- 定期回顾，把相关条目互相引用
