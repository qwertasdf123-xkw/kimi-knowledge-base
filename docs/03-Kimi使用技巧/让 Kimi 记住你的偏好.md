# 让 Kimi 记住你的偏好

## 适合记忆的稳定信息
- 身份与角色：「我是产品经理，负责 B 端 SaaS」
- 写作偏好：「回复用简体中文，语气直接，少用形容词」
- 常用格式：「会议纪要固定用结论+行动项+要点三段式」
- 长期项目背景：「我在跟进 X 项目，核心指标是 Y」

## 不适合记忆的
- 一次性任务的细节
- 频繁变化的信息（本周的优先级等）——放在对话里说

## 配合本知识库
把常用的角色设定、格式模板沉淀在知识库里，需要时直接引用，比口头描述更稳定。
