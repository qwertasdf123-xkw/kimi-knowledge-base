> 角色 + 背景 + 任务 + 约束 + 输出格式，五段式提示词结构。

# 万能任务拆解提示词模板

```
【角色】你是一位 ___领域的资深___。
【背景】我正在做 ___，目标是 ___。
【任务】请帮我 ___。
【约束】
- 要求 1：___
- 要求 2：___
- 不要：___
【输出格式】请以 ___ 的形式输出，包含 ___ 部分。
```

## 使用要点
1. **角色**让回答更专业，但别堆砌——一个精准角色胜过三个空泛头衔
2. **背景**越具体，答案越贴合（说"给投资人看的 BP"比"写个 BP"好十倍）
3. **约束**写否定项同样重要："不要套话""不要超过 500 字"
4. **输出格式**能省去大量返工
